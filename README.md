## Hello — saya Fairuz

Saya merupakan siswa PPLG di **SMK Negeri 1 Kota Bengkulu** yang mengembangkan aplikasi web, desktop, Android, dan sistem berbasis data. Di luar pemrograman, saya aktif mendokumentasikan biodiversitas, melakukan observasi lapangan, dan berkontribusi dalam publikasi herpetologi.

I enjoy projects that connect careful engineering with real-world observation: useful software, responsible security research, structured data, and field documentation.
